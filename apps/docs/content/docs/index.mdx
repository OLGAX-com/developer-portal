The **Olgax Community Platform** is an open-source community and mentorship platform built around
GitHub. It helps students, developers, mentors, and maintainers collaborate on real open-source
projects while providing structured learning, mentorship, recognition, and contribution tracking.

GitHub remains the source of truth for code. Olgax is the source of truth for community.

## A note on documentation

This site (`apps/docs`) only covers the **platform itself**. Documentation for individual
open-source projects tracked in the ecosystem (e.g. `olgax-pos`) is never duplicated here — it's
synced and rendered live from each project's own GitHub repository on that project's page in the
main app.
